# TinyMCE table extension

`table.min.js` is the unmodified TinyMCE 4 table extension shipped by [Advanced Editor Tools 5.10.1](https://wordpress.org/plugins/tinymce-advanced/), distributed under [GPL v2](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html). The tagged [minified file](https://plugins.svn.wordpress.org/tinymce-advanced/tags/5.10.1/mce/table/plugin.min.js) and [corresponding source](https://plugins.svn.wordpress.org/tinymce-advanced/tags/5.10.1/mce/table/plugin.js) are available in the WordPress.org repository.
