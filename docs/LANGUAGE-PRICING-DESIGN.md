# Новий блок цін у шаблоні мови

Статус — реалізовано й перевірено локально 2026-11-15 після погодження структури користувачем. Публічний випуск production очікує окремої команди.

## Межі зміни

Джерело дизайну — [макет](https://claude.ai/artifact/TyrCMVGXxX9prnCgUvsWsH#artboard-31c826a7b16b). Новий блок займає місце поточного блоку цін у `template/template-language.php`. На локальному знімку цей шаблон використовують 13 сторінок. Англійська та іспанська для дорослих використовують інший `template/template-rozvod.php`; їх включення потребує окремого рішення.

У макеті є заголовок, перемикачі типу курсу, тривалості та рівня, картки 8/24/48 уроків, банки, пояснення розтермінування, додатковий текст і телефонна форма. Варіанти перемикаються в цьому блоці. Картки та перемикачі не містять посилань. Кнопка форми використовує наявний обробник `ed_callback`.

## ACF на кожній сторінці

Нова локальна PHP-група полів прив'язується до шаблону `template/template-language.php`. Старі `cni`, `taba`, `tegi_tretogo_bloku` та інші поля старого блоку зберігаються для чинного відображення.

| Поле | Тип ACF | Зміст |
| --- | --- | --- |
| Типи курсу | Repeater | Стабільний ID і редагована назва |
| Тривалості | Repeater | Стабільний ID, кількість хвилин і підпис |
| Рівні | Repeater | Стабільний ID і редагована назва |
| Комбінації та ціни | Repeater | Посилання на три ID, статус і ціни за урок у пакетах 8, 24, 48 |
| Оформлення | Group | Заголовок, підписи карток, позначка вигідного пакета, банківські іконки, пояснення, текст кнопки |

Списки належать конкретній мовній сторінці. Редактор може додавати, перейменовувати, переставляти й видаляти варіанти. Нові ID створюються автоматично. Зв'язки цін з варіантами використовують ID, а не назви чи номери рядків.

Адмінський JS формує рядки комбінацій з цих трьох списків і оновлює підписи без втрати вже заповнених значень. Звичайні ACF repeaters зберігають дані у штатному postmeta. Власний тип таблиць БД не потрібний.

Приклад для двох курсів, трьох тривалостей і двох рівнів — 12 комбінацій і 36 незалежних цін. Для кожної з них вводиться ціна одного уроку, без автоматичного припущення щодо знижки чи вартості іншого пакета.

## Перевірки й незаповнені значення

- Ціни — числові поля у гривнях, більше нуля, з підтримкою копійок.
- Кожна комбінація має статус «Чернетка», «Доступна» або «Не пропонуємо».
- Для доступної комбінації потрібні всі три ціни. Для чернетки дозволено часткове заповнення.
- Дублікати трійки ID заборонені. Збереження перевіряється сервером через ACF.
- Після видалення варіанта пов'язані ціни позначаються як неактуальні. Вони зберігаються для відновлення та не передаються у віджет.
- Перейменування та зміна порядку не змінюють прив'язку цін.
- Нові варіанти створюють чернеткові комбінації. Порожня ціна не стає нулем і не підміняється сусідньою.
- Для великої кількості рядків адмінка повинна попереджати про наближення до серверного `max_input_vars`, щоб уникнути неповного збереження.

## Відображення та форма

Кожен перемикач змінює поточну трійку ID, за якою вибираються три ціни. Доступні значення передаються через JSON із сервера, а JS змінює числа й активні стани. Для недоступної комбінації відображається пояснення без чужих цін. Початковий стан обирається з доступних заповнених комбінацій.

Вибір доступний із клавіатури. На мобільному пристрої групи перемикачів переносяться, а картки складаються вертикально. Стилі обмежені цим блоком, вихідні SCSS/JS входять у штатну збірку теми. Публічні SEO-заголовки зберігають рівень і потрібний текст сторінки.

Форма використовує наявний ed_callback і заголовок сторінки. Відвідувач залишає заявку на пробний урок. Вибір оплаченого пакета в цьому макеті відсутній.

## Заповнення й майбутня публікація

Спочатку поля можна заповнювати й переглядати редакторським попереднім переглядом. Новий блок на публічному сайті залишається вимкненим окремим загальним перемикачем релізу, недоступним контент-редактору. Збереження цін саме по собі не вмикає новий дизайн.

Перед публікацією потрібно перевірити всі сторінки цього шаблону — кожна поточна комбінація повинна бути заповнена або явно позначена «Не пропонуємо». Після окремої команди користувача новий блок можна ввімкнути. За неповних чи некоректних даних залишається старий блок.

## Перевірка реалізації

Збереження й повторне відкриття ACF; додавання, перейменування, перестановка й видалення варіантів; різні ціни всіх комбінацій; недоступна й незаповнена комбінації; захист від дублікатів і невідомих ID; робота форми; десктопний і мобільний вигляд; відсутність нового блоку в публічному HTML до випуску; повторна збірка assets.

## Як заповнювати

1. Відкрийте сторінку зі «Шаблоном мови» та блок «Блок цін — поточний / Ціни v2» під заголовком сторінки.
2. У полі «Який вигляд блоку використовувати» оберіть «Ціни v2».
3. Додайте потрібні типи курсів, тривалості та рівні. Назви редагуються окремо для кожної мови.
4. Натисніть «Створити відсутні комбінації». Повторне натискання зберігає ціни й не створює дублікатів.
5. У кожному рядку вкажіть ціни одного уроку для пакетів 8/24/48 і стан «Ціни заповнено». Для неповного рядка залиште «Чернетка», для непотрібного — «Не пропонуємо».
6. Збережіть сторінку та відкрийте «Переглянути збережені Ціни v2» праворуч. На production посилання потребує входу редактора.
7. «Поточний блок» повертає старий вигляд, зберігаючи введені ціни v2.

Для чотирьох SEO-сторінок цього шаблону заголовок береться зі старого поля «Заголовок блоку зі списком». Решта використовують нове поле заголовка. Це пояснено біля нового поля.

## Реалізація й перевірки

- inc/language-pricing.php реєструє native ACF repeaters, перевіряє ціни та унікальність комбінацій і закриває публічний випуск.
- template/template-language.php перемикає старий блок і parts/content-language-pricing.php. parts/pricing-options.php виводить доступні з клавіатури radio-перемикачі.
- Адмінський генератор і frontend-контролер мають вихідники в src/js/libraries і копії в assets/js/libraries, які відновлює Gulp copy.
- Окремий src/scss/pricing.scss входить у Gulp scss/scssBuild разом зі style.scss. assets/css/pricing.min.css підключається лише для нового блоку. Поточний загальний CSS не перескладався.
- Іконки банків перевикористано зі старого блоку в src/img/pricing-banks.svg та assets/img/pricing-banks.svg; ACF дозволяє замінити зображення.
- На локальній польській сторінці підготовлено 2 типи курсів × 2 рівні × 3 тривалості = 12 чернеткових рядків, без цін. Інші сторінки автоматично отримали редактор через прив'язку до шаблону.
- Native ACF save перевірено у браузері, включно з перейменуванням рівня та збереженням трьох цін. Генератор при повторному запуску додав 0 рядків.
- На тимчасових локальних значеннях у браузері перевірено всі 12 комбінацій і 36 цін. Після перевірки значення видалено. Перевірено desktop 1366 і mobile 390, переповнення блоку та сторінки відсутнє.
- scripts/verify-language-pricing.php перевіряє стабільність ID, перейменування/порядок, видалені варіанти, чернетки, дублікати, недоступні комбінації, некоректні суми й native ACF POST. Перевірки пройшли на локальному WordPress, PHP lint пройшов також на 7.4.
- Повернення польської до старого вигляду перевірено повторним проходженням scripts/verify-seo.py для шести локальних SEO-сторінок.
- Автоматичний UI-аналізатор позначив нижню межу 3 px на перемикачі. Це активне підкреслення з погодженого макета, тому його збережено.

## Випуск

Локально обрана v2 відображається для перевірки й наповнення. На production гостям потрібні одночасно pricing_visual=v2, повна валідна матриця та EDUCADO_PRICING_V2_PUBLIC=true. За замовчуванням константа відсутня, публічний випуск закрито. Редакторський preview додатково перевіряє право редагування та nonce і вимикає кешування.
