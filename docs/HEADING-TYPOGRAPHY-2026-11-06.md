# Восстановление размеров заголовков из Git

Проверены `.appointment-title.h1` «Допомагаємо заговорити іноземною» и общая типографика `.h1`.

В `907d2bd` размеры были 70 px на широком desktop, 50 px до 1780 px, 32 px до 640 px. Коммит `90e8657` от 2026-06-25 заменил размеры в SCSS на `min(3vh, 70px)` / `min(5vh, 32px)`; в собранный CSS изменение вошло в `bbb80af` от 2026-07-30. Они уже присутствовали в Git HEAD и на production до текущего SEO-задания. При 1920×1080 это давало 32,4 px вместо прежних 70 px.

Исторический миксин `h1` восстановлен в `src/scss/helpers/_fonts.scss`, вместе с двумя соответствующими размерами в `assets/css/style.min.css`. Шрифт Poiret One, line-height и брейкпоинты сохранены. Изменения применены локально и на хостинге.

Чтобы полный билд не удалял отдельный SEO-стиль, правила перенесены из `assets/css/language-seo.css` в `src/scss/_language-seo.scss`, импортируемый из `src/scss/style.scss`. Отдельное PHP-подключение удалено: правила входят в обычный `style.min.css` и ограничены классами целевых блоков.

Настоящая задача `gulp/task/scss.js::scssBuild` проверена с тем же входным `src/scss/style.scss`, Sass, autoprefixer и rename, но выводом во временную папку вне проекта. Код завершения 0; результат содержит размеры 70 / 50 / 32 px и SEO-правила. Весь production CSS из неполного размещённого SCSS-дерева не пересобирался.

В Chrome для указанного пользователем заголовка:

| Окно | font-size | line-height |
| --- | --- | --- |
| 1920×1080 | 70 px | 79,8 px |
| 1920×720 | 70 px | 79,8 px |
| 1440×900 | 50 px | 57 px |
| 390×844 | 32 px | 37 px |

Горизонтального переполнения нет. На production подтверждено 70 px; длинные заголовки языковых страниц также проверены с размерами 70 px и 32 px на мобильном. Результаты: `heading-build-verification.json`, `heading-browser-verification.json`.
