## Перевірки

PHP lint пройшов локально та на сервері перед заміною файлів. Перед записом ACF скрипт звірив вихідні значення та шаблони. Після запису виконано readback усіх змін. Для повторювачів змінюються лише потрібні текстові підполя: форматовані ACF link-поля не можна записувати назад як рядки URL.

Перша спроба запису цілого повторювача напрямків англійської очистила п'ять link-значень; перевірка зупинила скрипт. Сирі масиви link-полів відновлені з SQL-копії та звірені, після чого скрипт виправлено на точкові `update_sub_field`. Завершальний readback повторювачів підтвердив збереження посилань, цін і вкладеного контенту.

`scripts/verify-seo.py` перевіряє всі шість опублікованих сторінок: один H1, відсутність пропусків рівнів, потрібні тексти H2/H3, сім питань FAQ, списки переваг, відсутність порожніх блоків для початківців, точний вміст і HTTP 200 для robots/llms. Результат: `docs/seo-verification.json`.

У Chrome перевірено два шаблони на десктопі та при ширині 390 px: горизонтального переповнення немає; FAQ розкривається, вкладки французької перемикають контент. Обчислені стилі шести наявних елементів англійської до/після заміни тегів збіглися. Перевірка форм із відправленням не проводилася.

## Відкат

Для повернення текстів використовувати значення `before` з `scripts/seo-content-20261106.json`, записуючи лише змінені текстові підполя через ACF. Не записувати назад форматовані link-поля. Шаблони та `functions.php` до змін є в Git; перед відкатом звірити поточні зміни. `llms.txt` до змін збережений окремо; нові поля можна залишити порожніми. Повний імпорт SQL не потрібний для точкового відкату й може затерти пізніші записи.

Подальша синхронізація локальної бази, зображень і файлів production та підготовка до Git описані в [окремому звіті](LOCAL-PRODUCTION-SYNC-2026-11-06.md). Попередні локальні файли теми збережено в ZIP перед заміною; підтверджені production-версії входять у коміт разом зі змінами ТЗ.
